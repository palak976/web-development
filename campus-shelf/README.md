CampusShelf 📚

A simple library catalogue website that helps students find reference books, check their availability, and locate them on library shelves.

Features

-  Search for books by title, author, subject, or course code.
-  View book details and subject information.
-  Find the shelf location of each book.
-  Check the number of available copies.
-  Simple and user-friendly interface.

Built With

- HTML
- CSS
- JavaScript

Getting Started

1. Clone this repository:
   git clone https://github.com/palak976/web-development.git

2. Open the CampusShelf project folder.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
